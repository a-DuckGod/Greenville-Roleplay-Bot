# Security Policy

## Reporting a Vulnerability

This repository is maintained under **KGVRP** (*Known-Good Vulnerability Research & Patching*, <https://kgvrp.com>).

If you discover a security vulnerability, exposed secret, or dependency risk in this project, please do **not** open a public GitHub issue. Instead, report it privately via one of the following channels:

- **Email:** `aduckgod@kgvrp.com`
- **GitHub:** Use **Private vulnerability reporting** under the repository's **Security** tab (if enabled).
- **Organization Policy:** <https://kgvrp.com/#security>

Please include:
- Affected component, command, or endpoint
- Steps to reproduce or proof-of-concept details
- Potential impact and any suggested remediation

We acknowledge coordinated disclosure reports promptly and validate patches prior to any public advisory.
