Privacy Policy

Last updated: November 16, 2026

1. Introduction

This Privacy Policy explains what information the Greenville Roleplay Bot ("the bot") collects, how it is used, and how you can have it removed. It applies to every Discord server that invites the bot and to every member who interacts with it. This policy should be read together with our Terms of Service.

2. Information We Store

The bot stores only what it needs to work. All stored data is kept in a SQLite database on the bot's host.

Server configuration (saved when a server admin uses /config):

  • Server (guild) ID
  • Command prefix
  • Rules channel ID and session announcement channel ID
  • Staff/Host role IDs, Early Access role IDs, and Booster role ID
  • Startup and release ping settings (@everyone, @here, a role ID, or none)
  • Default reaction goal and startup reaction emojis

Session links (saved when a host uses /ea or /release), so that join buttons keep working after a restart:

  • The ID of the announcement message and the server it was posted in
  • The session link the host provided (for example, a Roblox private server URL)
  • The Discord user ID of the host who posted it
  • The type of link (Early Access or Release) and the time it was posted

The bot does not store message content, usernames, nicknames, avatars, member lists, or any information about members who simply press a button or react to a post.

3. Discord Permissions and Intents

The bot uses two privileged Discord gateway intents. Neither is used to store data.

  • Message Content Intent: used only to recognize prefix commands (for example, -startup). Messages are read in the moment to check for a command and are not saved. When a prefix command is used, the bot may delete the triggering message to keep channels clean.
  • Server Members Intent: used only to check a member's roles at the time they run a command or press a button, so that staff commands and Early Access links are limited to the right people.

The /purge command deletes messages through Discord but does not copy or keep them.

4. How Information Is Used

Stored information is used only to:

  • Apply each server's own channels, roles, prefix, pings, and reaction goals
  • Decide who is allowed to use staff commands and Early Access buttons
  • Show the correct session link when a member presses a join button

We do not sell, rent, or share this information with third parties, and we do not use it for advertising, analytics, or profiling.

5. Hosting and Logs

The bot is hosted on Render, which stores the database and processes the bot's traffic on our behalf. The bot also writes basic operational logs on Render, which may include a server's name and ID when the bot joins and technical details when a command fails. These logs are used only for troubleshooting.

All information also passes through Discord, which handles it under the Discord Privacy Policy.

6. Data Retention and Deletion

  • Server configuration is kept until a server admin runs /config reset, which deletes it immediately, or until you ask us to delete it.
  • Session link records are kept so that join buttons on older announcements continue to work. They are not removed by /config reset.
  • When the bot is removed from a server, all of that server's configuration and session link records are deleted automatically.
  • Stored data may also be cleared when the bot is redeployed or moved to a new host.

If you are a host and want your user ID removed from session records while the bot is still in your server, email us with your server ID and user ID. We will delete the data within 30 days.

7. Security

We take reasonable steps to protect stored data, including keeping the bot token and database out of public view. No online service is completely secure, so we cannot guarantee absolute security. Security issues can be reported as described in this repository's SECURITY.md.

8. Children's Privacy

The bot is intended for use on Discord, which requires users to meet its minimum age requirement. We do not knowingly collect information from anyone below Discord's minimum age.

9. Changes to This Policy

We may update this Privacy Policy from time to time, for example when new features change what the bot stores. The "Last updated" date at the top of this page will change, and significant updates will be communicated through the bot or official channels.
